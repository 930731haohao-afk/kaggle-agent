# Pre-registrations — read through the filter only

Registered hypotheses live in `knowledge/knowledge_base.json` (the `prereg` key) and are
read via `python3 knowledge/task_priors_for.py <comp> --prereg`, which withholds any clause
whose only evidence is the competition being solved. The original prose registration is
archived at `knowledge/archive_pre_structured/horizon_length_form_selector.md` as the
historical record. `frozen_versions.md` (version pins) stays here — it carries no
competition results.
